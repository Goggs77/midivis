# midivis: An experimental microtonal MIDI visualizer and synthesizer in haskell

## Developmental Notes:
- This application is written with the help of deepkeek-v4-flash, which did the most parts of synthesizer module and portaudio integration.
- I used the agents to fix library issues and customize libraries.
- Currently this repo **has not** been in sync with the latest version of the project on my desktop computer for few weeks.
- This is an **experimental** project that does not focus on extreme performance. It's existence speaks for itself.

## Functions:
- Connect to an MIDI input
- Hot-switch tuning settings
- Play and hear the tuning in real-time
- (On local sources) Match the frequencies with both 12-TET and Just Intonation scales/chords
